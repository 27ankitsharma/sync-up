An AI agent is a **goal-directed loop** that can act and observe. A model predicts. Automation follows a fixed path.

## Remember

 - An agent independently works toward a goal; a workflow follows predefined steps. 
 - Use an agent when a task requires decision-making, context, adaptation or coordination. 
 - A model generates or transforms information; a tool performs a specific operation. 
 - Not every AI capability needs to become an agent. Keep narrow, deterministic tasks as tools or model calls. 
 - The key question is not "Can AI do this?" but "Does this task need autonomous decision-making?"
